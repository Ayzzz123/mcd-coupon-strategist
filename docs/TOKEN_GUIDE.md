# 麦当劳 MCP Token 申请指引

> 这一步涉及手机号实名验证，**必须你本人操作**，我无法代劳。全程约 3 分钟。

## 申请步骤

1. 打开麦当劳 MCP 开放平台：<https://open.mcd.cn/mcp>
2. 点击页面**右上角【登录】**
3. 跳转到登录页后，**使用手机号完成验证登录**
4. 登录成功会跳回首页，右上角的「登录」按钮会变成**【控制台】**
5. 点击右上角**【控制台】**，弹出控制台弹窗
6. 点击**【激活】**按钮，申请 MCP Token
7. **阅读并同意服务协议**
8. Token 申请成功后，点击**一键复制**

## 拿到 Token 后要做的事

回到 WorkBuddy，把 Token 填进配置：

1. 左侧边栏进入【专家 · 技能 · 连接器】→【连接器】页签
2. 点击右上角【自定义连接器】→【配置 MCP】
3. 粘贴以下 JSON，**把 `${MCD_MCP_TOKEN}` 替换成你的真实 Token**：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer 你的真实Token"
      }
    }
  }
}
```

4. 点击【保存】
5. 回到【自定义连接器】，把 `mcd-mcp` 设为**【启用】**

> 新配置的 MCP 不会自动生效。保存后需要在自定义连接器入口点击【信任】才能真正启用。

## 注意事项

| 事项 | 说明 |
|---|---|
| 频率限制 | 每个 Token 每分钟最多 600 次请求，超限返回 429 |
| 401 错误 | Token 无效、已过期或未提供，检查请求头与 Token |
| 429 错误 | 触发限流，降低请求频率 |
| **安全** | Token 等同于你的账号凭证，**绝不要提交到公开仓库** |

## 安全自查

提交参赛仓库前，务必确认：

- [ ] 仓库中**没有任何文件**包含真实 Token
- [ ] `mcp-config.example.json` 中只有 `${MCD_MCP_TOKEN}` 占位符
- [ ] `git log` 中没有历史提交泄漏过 Token

如果不慎提交过 Token，立即到控制台重新申请一个，旧 Token 作废。
