```text
【参赛申请】
项目名称：麦麦省钱助手（mcd-coupon-strategist）
项目地址：https://github.com/Ayzzz123/mcd-coupon-strategist
项目简介：身材管控、预算有限、选择困难？这个 Skill 基于麦当劳 MCP，在当前门店实时菜单与可用券的约束下算出最省钱的点餐组合。

与其他省钱类工具不同，本项目额外做两件事：
1. 主动检测「凑单陷阱」——当为触发券门槛而加购导致实付不降反升时，明确指出并给出不凑单的对照方案。多数工具只回答「怎么用券最省」，本项目还回答「这张券值不值得为它凑单」。
2. 所有金额均来自 MCP calculate-price 的真实返回，枚举与计价严格分离，从架构上杜绝模型猜测价格。

已用真实门店数据验证：麦辣鸡腿堡三件套实付 33.5 元，而等价单点组合需 46.5 元——套餐结构本身省 13 元，无需叠加任何优惠券。

技术说明：项目含 MCP 适配层，统一处理官方接口「分/元」单位换算与字段映射；配备两套纯本地测试（算法逻辑 + 适配层），无需 MCP Token 即可运行。使用 WorkBuddy 开发，并已提交 workbuddy.md。
```
