# 知乎发布操作清单

> 配合 `docs/ZHIHU_POST.md` 使用

---

## 一、发布形式：选「文章」，不要选「回答」

原因：

| | 回答 | 文章 |
|---|---|---|
| 能否被搜索引擎收录 | 差 | **好** |
| 能否加封面图 | 不能 | **能** |
| 站内推荐权重 | 依赖问题热度 | 独立分发 |
| 适合内容 | 针对性问答 | 项目分享 |

你这篇是「我做了个东西」的分享型内容，**发文章更合适**。

如果一定要发回答（能蹭流量），找这类问题下手：

- 「有哪些值得推荐的 GitHub 开源项目？」
- 「麦当劳的优惠券怎么用最划算？」
- 「MCP 是什么？有哪些实际应用？」
- 「2026 年有什么有趣的开源项目？」

## 二、怎么粘进知乎（不需要任何第三方工具）

知乎的富文本编辑器**不认 Markdown**，但好消息是：这篇文案我当初就是按「能被知乎直接接受」的格式写的，**不需要 md.aclickall.com 之类的转换工具**（那类站点经常挂）。

### 用哪份文件

| 文件 | 用途 |
|---|---|
| **`ZHIHU_PLAINTEXT.md`** | **正式粘贴用**。已清除所有 Markdown 标记，纯文本，直接全选复制 |
| `ZHIHU_GUIDED.md` | 带排版提示的辅助版，教你哪里该加样式（别复制里面的【】提示） |
| `ZHIHU_POST.md` | 原始 Markdown 版，留档用，不要直接粘 |

### 操作步骤（3 步，5 分钟）

1. 打开 `ZHIHU_PLAINTEXT.md`，**全选复制**
2. 粘进知乎编辑器（内容会原样成为段落，不会乱）
3. **手动做 3 处样式**（这是唯一需要动手的地方）：
   - 每处「一、」「二、」…开头的行 → 选中，点工具栏的**标题**按钮
   - 那几段 4 空格缩进的报告块（券成本 / 消费画像 / 测试命令）→ 选中，点工具栏的**代码块**按钮 `</>`
   - 开头「先说结论：」那一句 → 手动加粗

> 📌 页面里所有 `【设为标题 →】` 的提示文字，**操作完记得删掉**（在 ZHIHU_GUIDED.md 里才有，正式版没有）。

### 为什么不用第三方转换工具

我已经在源文案里规避了所有知乎的坑：

- **没用 Markdown 表格** —— 知乎粘贴表格会错行，所以「技术坑」部分改成了编号小节
- **没用行内代码反引号** —— 知乎不渲染它，会原样显示成 `` ` ``，所以字段名都写成普通文字
- **代码块内容用普通缩进** —— 靠缩进视觉效果保留，粘完手动设一次代码样式即可

**结果：粘完只需手动处理 6 个标题 + 3 个代码块，其余全部自动正确。**

## 三、封面图

知乎文章**必须传封面**，否则在信息流里只有一行字，点击率很低。

- 首选：`assets/social-preview.png`（1280×640，刚好符合知乎封面比例）
- 备选：仓库 README 顶部 banner（但它更长，会被裁）

正文中间建议插两张图，位置：

1. 第「二、券是有保质期的钱」之后 → 插 `assets/demo-dual-view.svg` 导出的 PNG
2. 第「六、项目地址」之前 → 插 `assets/architecture.svg` 导出的 PNG

> ⚠️ SVG 不能直接传知乎，需要先转成 PNG。可以让我帮你转。

## 四、发布时机

知乎的推荐机制是**发布后 1~2 小时内的互动数据决定后续分发量**。

所以：

- **别在深夜发**（没人看，初始数据差，直接判死）
- 推荐 **工作日 12:00-13:00** 或 **20:00-22:00**
- 发布后立刻分享到自己的微信群/朋友圈，**前 30 分钟的点赞和评论最关键**
- 前几条评论自己要回复，知乎很看评论区活跃度

---

## 五、发布后必做：在 GitHub 加 Discussion 引导

知乎那篇文章里放了仓库链接，但**知乎的外链是 nofollow 的**，且会弹「即将离开知乎」提示，跳转流失很高。

对策：在仓库里开一个 Discussion 置顶，标题类似：

> 「从知乎来的朋友，欢迎在这里留言」

然后引导他们 **先点 star 再提问**。这条对转化率提升很明显。

## 六、同步分发渠道（一稿多投，改标题即可）

同一篇内容，改个开头就能投：

| 平台 | 调整点 |
|---|---|
| **掘金** | 标题加「实战」二字，开头去掉「先说结论」的知乎腔，直接上技术 |
| **V2EX / 分享创造** | 标题改成「[分享] 麦当劳 MCP 省钱助手，反凑单陷阱」，纯技术口吻，别提「知乎」 |
| **即刻** | 只发前两段 + 项目链接，配 social-preview 图 |
| **小红书** | 需要重写成短句 + emoji 风格，标题「谁懂啊…我发现麦当劳的券会过期」 |
| **B 站专栏** | 和掘金版本一致 |
